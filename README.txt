EDYTOWALNA STRONA — INSTRUKCJA

1. Otwórz plik config.js.
2. Zmień teksty w CONFIG.
3. Zapisz plik.
4. Wrzuć index.html, style.css, config.js i script.js na hosting.
5. Otwórz adres swojej domeny.

NAJWAŻNIEJSZE:
- Nazwa firmy: brand
- Nagłówek strony: heroTitle
- Opis: heroText
- E-mail odbiorcy formularza: formRecipient
- Telefon: phone
- Oferta: services
- Sekcja "Dlaczego my?": features

FORMULARZ:
Domyślnie korzysta z mailto, więc nie wymaga PHP ani bazy danych. Po wysłaniu otworzy program pocztowy użytkownika. Jeśli chcesz formularz działający bez programu pocztowego, podłącz później backend lub zewnętrzną usługę formularzy.

HOSTING:
To jest zwykła strona statyczna — nadaje się m.in. na klasyczny hosting WWW, GitHub Pages, Cloudflare Pages, Netlify itp.

BEZPIECZEŃSTWO:
Nie wpisuj haseł, kluczy API ani danych prywatnych do config.js, ponieważ pliki strony są publicznie dostępne.
